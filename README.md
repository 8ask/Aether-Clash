# AETHER CLASH v12.4

Farm · Fight · Rebirth

This is the full source for the Roblox game **AETHER CLASH**.

## How to put it in Roblox Studio

1. Open Roblox Studio → create a new Baseplate (or empty place).
2. In **ReplicatedStorage**:
   - Create a **ModuleScript** named `ClashConfig`
   - Paste the entire contents of `ClashConfig.lua` into it
   - Create another **ModuleScript** named `ClashUtil`
   - Paste the entire contents of `ClashUtil.lua` into it
3. In **ServerScriptService**:
   - Create a **Script** named `ServerMain`
   - Paste the entire contents of `ServerMain.lua` into it
4. In **StarterPlayer → StarterPlayerScripts**:
   - Create a **LocalScript** named `ClientMain`
   - Paste the entire contents of `ClientMain.lua` into it
5. Settings:
   - Lighting → Technology = **Future**
   - Game Settings → Security → **Enable Studio Access to API Services** = ON
   - Avatar → R15
6. Publish the place, then set Permissions so Friends can join.

## Files

| File              | Location in Studio                          | Type         |
|-------------------|---------------------------------------------|--------------|
| ClashConfig.lua   | ReplicatedStorage → ClashConfig             | ModuleScript |
| ClashUtil.lua     | ReplicatedStorage → ClashUtil               | ModuleScript |
| ServerMain.lua    | ServerScriptService → ServerMain            | Script       |
| ClientMain.lua    | StarterPlayer → StarterPlayerScripts → ClientMain | LocalScript |

That's it. No extra models required — the map is generated by the server script.
